## 목적

v0(`index.html` 1.2k 라인, 라운드 1 규칙)를 **v2 규칙의 1막→2막 1사이클**로 교체해, 제안서 §7 kill-criterion 을 **지인 2~4인 + 셀프 플레이로 판정할 수 있는 한 덩어리**를 만든다. 슈퍼센트 과제 제출물(마감 2026-09-07), 판정일 2026-09-02 저녁.

재미 가설은 하나 — **"손으로 익힌 초식이 자동화되는 순간이 보상이다"**. 프로토타입에서 "자동화"는 **제자가 내 무공을 대신 구사하는 것**이고, 그 자격은 내 손이 그 무공을 완벽히 깨달았다(12성)는 증표다. 성립 조건 넷:

- **(a) 입력 = 선택 + 실행** — 후보 필터 입력에서 선택은 **후보가 갈라지는 분기 키**에서 일어나고 그 뒤 꼬리가 실행이다. 같은 비급의 초식은 같은 첫 키로 시작해 도중에 갈라지므로 비급 1권인 프로토타입에서는 2번째 키가 선택 축, 다권(M2+)이면 첫 키부터 비급 단위로 갈라진다(스케일에 따라 분기점이 이동할 뿐 규칙은 같다). **지금 보이는 내 속성 색 = 현재 후보 리스트 최상단 초식의 속성** — 키를 칠수록 색이 답하고, 수동 입력은 도중에 갈래(속성)를 바꿀 수 있지만 원터치는 고정이다. 정답 1개 강제였던 v0 엔 이 축이 없었다.
- **(b) 숙련 = 손의 권한, 성 = 깨달음의 증표 (두 축)** — 초식 단위 **숙련도** 0~100%: 힌트(0~30%) → 후보만(30~99%) → **원터치(100%)**. 무공 단위 **성(成)** 1~12: 위력이 오르고 10성이 통상의 최고, 11·12성은 파해를 완파한 자만 — **12성 = 전수 가능·분해 가능**. 원터치를 얻는 것과 전수는 다른 축의 다른 종점이라 서로 잡아먹지 않는다. 시퀀스 입력은 **유저 전용** — 사부 자동응수 토글은 없다.
- **(c) 순차 해금 → 12성 → 전수(복사) → 파견** — 하위 초식 100% 가 다음 초식의 학습 조건이라 사다리가 명확하고, 12성에 이르면 무공을 제자에게 **복사**해 준다. 제자는 성·레벨이 있는 자동 용병 — 유저는 **어느 제자를 세울지·어느 초식을 쓰게 할지 선택**만 하고 실행은 자동. 2막의 해방 = "내가 손으로 치던 유운검법을 탭 하나로 시키는 첫 파견".
- **(d) 자명성** — 튜토리얼 없이 첫 초식 발동 ≤ 60초. "예고 색 → 내 후보 색 대조" 와 자동완성식 후보 축소가 설명 없이 읽힌다는 가설.

**판정 형태** (n=2~4 에서 성립하는 것만): kill 4항은 **개인별 pass/fail 의 과반**. (a) 첫 발동 60초 · (c) 전수 설문은 **지인 전용**(설계자·봇은 답할 수 없음), (b) 힌트 소멸 후 성공률 · (d) 완주 300초는 지인 + 셀프, **봇은 페이스 회귀 참고치**(판정 표본 아님). 비율 임계는 개인 세션 안에서 각자 pass/fail 을 내는 기준이지 표본 평균이 아니다. 판정은 **기본 설정**(접근성 옵션 off)에서. 제안서 §7 "본인 + 지인 2~4인, 설문 1문항" 의 구체화.

**통합 1개로 만드는 이유**: 6 서브시스템이 한 상태기계의 부품(여행자의 단어장 M1 작업 7 — 분할이 통합 결함을 마지막에 노출) + 단일 파일. 대가는 ⑥ 의 서브시스템별 로그 + build 순차 이슈로 상쇄.

## 내용

**MVP 스코프**: 비급 1권 「유운검법」 4식 · 도전자 A(사부 대련, 재도전 가능) + 도전자 B(파견 대련) · 실전 슬롯 3 · 제자 1명(레벨 1 = 무공 슬롯 1) · 6단 판정 · 수련 시뮬 · 로그 내보내기. **범위 밖**: 사부 자동응수(삭제, 개념 자체 없음) / 커버(삭제) / 오프라인 타임스탬프 정산·HMAC 세이브(M2) / 제자 2명+·레벨업·고용(M2) / **재화 소비처**(M2+: 장비 — 무기·의복 / 소모품 — 내공 증진·체력 회복 / 무공 비급 구매 / 도장 운영 / 제자 고용·레벨) / 원정 모드(제자를 보내 비가시 임무 → 복귀 보고: 전투 횟수·전리품 — S1 후보, 오프라인 축과 결합) / 상대 쪽 진행형 색·허초·변초(S2) / 무공 분해·조합 창작·진법(S3) / 광고·IAP / 아트·사운드 실파일(M3 — 코드 렌더·Web Audio 합성 폴백).

**1사이클 순서와 시간 예산** (목표 300초; 4식은 사이클 뒤 계속 플레이 구간):

| 구간 | 내용 | 예산 |
|---|---|---|
| 0~40s | 비급 입수 → 유운보 수련 모드 5회 → 30% (장착 가능) | 첫 발동 ≤ 60s (kill a) |
| 40~100s | 도전자 A 1차(적 초식 α·β) — 유운보 실전 6회 성공 → 100% 원터치 · α 완파(파해) → 성 상승 | |
| 100~160s | 2식 해금·수련 5회 → 30% · 도전자 A 2차(γ 추가) — 2식 6회 → 100% · β 완파 | 첫 선택(후보 2) 등장 |
| 160~220s | 3식 해금·수련 5회 · 도전자 A 3차 — 3식 8회 → 100% · 유운검법 **12성** | |
| 220~240s | **전수** — 유운검법을 제자에게 복사(시연 1회 + 제자 미러 + 스팅어) | 첫 전수 ≤ 240s |
| 240~300s | **파견** — 도전자 B(α·γ + 절초 δ 공개)를 제자가 상대, 유저는 매 수 초식 탭 선택(무탭 시 자동) → 등급 「고수」 | 완주 ≤ 300s (kill d) |

수 하나 ≈ 예고 1.0 + 창 ~2.6 + 연출 0.5 ≈ 4~4.5s. 성공 발동 총 ≈ 수련 15 + 실전 20 = 35회 → 성 10(성공 3회당 1성) + 완파 2회(11·12성). 4식(5길이)은 파견 뒤 도장에서 해금 — δ 의 파해라 "다음 파견에서 δ 를 완파하려면" 이 사이클 후 동기.

**아키텍처 원칙**: `BALANCE` 단일 객체 + 상태기계 1개(도장 / 사부 대련 / 전수 / 파견 대련) + 초식·무공·도전자·제자 테이블 JSON + 로그 버퍼. 판정·숙련·성·전수·제자 선택은 순수 함수(헤드리스 하네스 DOM 없이). ①~⑥ 경계 = build 순차 이슈 경계.

### ① 후보 필터 시퀀스 입력부 (유저 전용)

- **비급 첫 키 공유·2번째 키 분기**: 유운검법 4식은 모두 `↓` 로 시작(초식 식별자 = 고유 시퀀스, prefix-free; 속성은 초식별 값으로 한 비급 안 혼재). 다권(M2+)이면 비급마다 첫 키가 달라 첫 키부터 갈라진다.
- 장착 = 실전 슬롯 3(장착 조건 숙련 ≥ 30%). 키마다 `candidates = 버퍼를 접두어로 갖는 장착 초식`, **정렬 = 숙련 높은 순 → 동률 슬롯 순**(결정적). **후보 0 이 되는 키 = 오입력 무시**(버퍼·후보 불변). 리셋 버튼(모바일 고정 타깃 / `Space`·`Esc`)만. **발동 = 후보 1 ∧ 버퍼 == 시퀀스** → `fire{styleId, r}` → ②.
- **진행형 후보 색**: 후보 리스트 최상단 초식의 속성이 "지금 내 색"으로 크게 표시(리스트 헤더 + 버퍼 색). 키를 쳐서 최상단이 바뀌면 색이 바뀐다 — 유저는 상대 색(예고, 확정 1색)을 보며 자기 후보를 좁힌다. 후보가 처음부터 1개면 색은 즉시 확정. 원터치는 색 고정(그 초식). 상대 쪽 진행형 색은 S2 변초의 표현으로 범위 밖.
- **읽기·판단은 예고 구간, 실행은 응수 창**: 예고 **1.0s**(판정 설계 0.5s → 상향), 창 `T = 2.6 + 0.5 × (len − 3)`(3/4/5 = 2.6/3.1/3.6s — v0 `windowMs` 길이 2/3/4 = 2200/2600/3000 의 같은-길이 승계 + 긴 초식만 여유; D3 튜닝은 줄이는 방향). 봇 스펙(반응 0.45~0.65 + 키당 0.26~0.38)으로 5길이 = 2.55s + 분기 판단 0.5s < 3.6s. 접근성 ×1.3 옵션(기본 off).
- 입력 소스 3중: 방향키 / WASD / 스와이프 → `onDirection(dir)`. 스와이프 = Pointer Events, 임계 24px, dominant-axis ≥ 1.5. **입력 시도 3종 전부 피드백**: 수락 / 무시(후보 0 — 셰이크 200ms + 회색 화살표 튕김 + 둔탁음) / 미인식(축 미달 — 궤적 끝 `?`, 로그 `swipe_reject`).
- 후보 표시: 아이콘(속성 3색 테두리 + 형태 ▲●■). 0~30%: 후보 아래 잔여 화살표 힌트 / 30~99%: 아이콘만 / 100%: 아이콘 탭 = 원터치. 후보 1 도달 시 중앙 확대 + 이름. 버퍼 한 줄(v0 `#seq`).
- `assertPrefixFree(styles[])`: 로드·장착 시 assert(⑤ 와 동일 함수).

### ② 6단 공방 판정부 (데이터 드리븐 + 헤드리스 하네스)

- 한 수: 예고 1.0s(상대 초식 아이콘 + 속성 색 확정 + 조짐) → 창 `T` → 교차 판정 → 연출 0.5s. 대련 = HP 소진 또는 12수.
- 판정표(판정 설계 §2-2): 파해 → 완파(100% + 상대 빈틈) / 속성 승 → 우세(60/20) / 동속성 → 상쇄(내공차 × k) / 속성 패 → 열세(20/60) / 상대 절초의 파해 대상을 냄 → 역파(0/100 + 나 빈틈) / 미완주 → 피격. 쾌>강>정>쾌, 파해 우선.
- 수식: `D` 10/14/20 · **내공 `N = 1 + 0.05 × 성`**(무공 성 기반으로 재정의 — 판정 설계 §3 의 숙련 기반 `N` 을 대체; 10성 1.5, 12성 1.6. 내공 소모 자원은 M2) · 선기 `1 + 0.3r` · 상쇄 `max(0, ΔN) × D × k`(0.5) · 빈틈 1수.
- 전부 `BALANCE` JSON, 순수 함수 `judge()` 로 6단 × 빈틈 × 선기 × 성 전 조합 하네스 회귀. 판정표 변경 = 하네스 기대값 같은 커밋.
- 정보 노출: 상대 속성 색 항상(예고 확정) / 내 진행형 후보 색 항상 / 파해는 구결 텍스트만 / 절초 1개는 도전자 예고 / 잔여 힌트 0~30% 만. **우세 후보 강조(펄스)는 두지 않는다** — 진행형 색이 그 정보이고, 열세·역파를 맞아 "색을 봐야 한다"를 배우는 것이 § 플레이의 재미. **삼각 한 줄**(`쾌 > 강 > 정 > 쾌`, 예고 속성 항 강조)은 **2식 해금 직후 첫 5수**만(`BALANCE.triangleHintExchanges`).

### ③ 숙련(초식) · 성(무공) · 순차 해금 · 실전 슬롯 · 전수

- **숙련도**(초식 0~100%): 수련 모드 5회 성공 → 30%(졸업·장착 가능) / 실전 성공(판정 ≥ 상쇄) 누적 `threshold`(유운보 6 · 2식 6 · 3식 8 · 4식 8 — v0 승계) → 100% = 원터치. 슬롯에서 빼도 보존.
- **순차 해금**: N식 숙련 100% → N+1식 학습 가능(도장에서 「배우기」). 재화 가격 게이트 없음.
- **성**(무공 1~12): 그 무공 초식의 성공 발동 누적 3회당 +1성(1→10). **11성 = 완파 1회, 12성 = 다른 초식으로 완파 1회 더**(파해를 아는 자만). 성 → 내공 `N`. 성 상승은 무공 카드에 「N성」 배지 + 짧은 연출.
- **실전 슬롯 3**: 4식이 열리는 순간 4 > 3 이라 "무엇을 장착할지" 선택 발생(도장에서만 교체).
- **전수 = 복사**: 조건 = 무공 12성 ∧ 제자 무공 슬롯 여유. 사부는 무공·숙련·성을 그대로 보유. 의식 = 사부 시연 1회(제자 궤적 0.3s 미러) + 스팅어 + 「전수」 연출 1.0s. 12성 무공은 분해(초식 재료) 가능 — 표시만(S3).
- 단계 라벨: 문하생 → 고수(첫 전수). 사부·일대종사는 M2+.

### ④ 제자 = 자동 용병 · 파견 대련

- 제자 1명(레벨 1 · 무공 슬롯 1). 제자의 무공에도 **성 1~10**(사용 누적으로 상승, 12성은 유저만) — 프로토타입은 표시 + 상승만. 제자 성공률 `p = 0.6 + 0.04 × 제자성`(1성 0.64 → 10성 1.0), 실행 시점 = 창의 40%.
- **파견 대련**(사부 대련과 별도 시간): 도전자 B 와 제자가 대련. 매 수 예고 1.0s 동안 유저가 **제자 무공의 초식 아이콘을 탭**해 선택(색 대조 — 원터치와 같은 촉감, 실행은 제자) / **무탭 시 자동 선택**(상대 속성에 우세인 초식 중 성 높은 것; 없으면 상쇄). 시퀀스 입력 없음, 커버 없음.
- 제자 실패(성공률 판정 실패) = 피격. 제자 패배 = 도전자 도주(손실 없음). 파견 결과 화면: 승패 · 성 변화 · 재화.
- 원정(비가시·보고형)은 S1 — 파견의 오프라인 버전.

### ⑤ 데이터 — 유운검법 4식 · 도전자 A/B · 도전자 예고

- 초식 테이블: id · 무공 · 이름 · 한자 · 속성 · 시퀀스(첫 키 `↓`, 2번째 키 분기) · `D` · 파해 대상 · 구결. 4식 = 유운보 쾌 3(`↓→↑`) · 2식 강 3(`↓←→`) · 3식 정 4(`↓↑→←`) · 4식 쾌 5(`↓↓→←↑`) — 속성 혼재라 분기 키 = 속성 선택.
- 무공 테이블: 유운검법 {초식 4, 성 1~12, 전수 조건}. 제자 테이블: {레벨 1, 무공 슬롯 1, 성 map}.
- 도전자 A(사부, 재도전 3차: α → α·β → α·β·γ, 절초 없음; α 파해 = 유운보, β = 2식, γ = 3식) / 도전자 B(파견: α·γ + 절초 δ 공개, δ 파해 = 4식 — 프로토 사이클엔 없어 상쇄·열세로 버팀 → 4식 동기).

## 예상되는 플레이와 기대하는 재미

- **0~60초 (긴장)**: 비급을 열면 유운보(청). 도전자 예고에 적(강) → 장착이 유운보뿐이라 첫 키에 후보 1, 내 색도 청으로 확정 → 힌트 화살표 따라 완주. "색 확인 → 따라 치기" 두 걸음. 상대 α 를 유운보로 파하면 「완파!」 + 빈틈 → 연환 — 첫 카타르시스.
- **1~3분 (숙달·선택)**: 30% 에 힌트가 사라지고 꼬리는 손이 친다. 유운보 100% 에 원터치가 열리면 선기 +30% 가 숫자로. 2식(강)이 들어오는 순간 `↓` 뒤에 **후보 둘, 내 색이 최상단(유운보·청)** — 예고가 청(쾌)이면 청으로 가면 상쇄, `←` 로 갈라져 강으로 가면 열세… 한 번 맞고 **색을 보게 된다**. 3식(정)이 오면 청 예고에 정이 우세라는 걸 삼각 줄이 알려주고 `↑` 로 갈라지며 색이 녹으로 바뀌는 게 보인다 — "입력할수록 화면이 답한다". 완파 두 번에 유운검법 **12성**.
- **3.5~4분 (전수)**: 12성 배지가 빛나고 제자 카드에 「전수 가능」. 시연 한 번, 제자 궤적이 따라오고 스팅어 — 무공은 내게 남고 제자에게도 생긴다.
- **4~5분 (해방·파견)**: 도전자 B 예고에 절초 δ(정). 제자를 보낸다. 매 수 예고 1초 동안 제자 초식 아이콘 셋 중 하나를 **탭** — 내가 치던 유운검법을 탭 하나로 시킨다. 안 눌러도 제자가 알아서 친다. δ 는 파해가 없어 버티고, 이기면 「고수」. "4식을 배우면 δ 도 완파" 가 다음 동기.
- **실수 경험**: 오입력 무벌(셰이크), 갈래 오진입도 유효 응수(색이 바뀌는 걸 보고 알아챔), 미인식 `?`.
- **검증 로그 → 개인별 pass/fail**: (a)(c) friend / (b)(d) self+friend — 4항 각각 과반 fail 이면 kill(제안서 §7 → B안 「퍼즐용사」 피벗). 보조 지표는 D3 튜닝 입력.

## 예상되는 문제점과 해결 방안

1. **2식 해금 직후 첫 선택에서 멈춘다** — 후보가 둘이 되는 순간 어느 갈래로 갈지 모른다.
   → 해결: 순차 해금이 후보를 1→2→3 으로 키우므로 그 순간까지 이미 예고 색을 10수 넘게 봤고, 그 첫 5수만 **삼각 한 줄**을 띄운다. 진행형 색이 "지금 가는 갈래의 색"을 보여줘 예고 색과 대조 가능. 우세 후보 직접 강조는 없음(학습 보호).

2. **오입력·미인식이 "안 눌린다"로 읽힌다**.
   → 해결: 3종 피드백(수락/무시/미인식) + 같은 창 무시 3회 → 리셋 하이라이트. 로그 분리.

3. **잘못 든 갈래로 좁혀졌는데 모른 채 완주**.
   → 해결: 갈래를 잘못 들면 **내 색이 바뀐다**(진행형 색) + 후보 1 도달 시 확대·이름 표시 / 장착 조건 ≥ 30% 라 잔여 시퀀스를 안다 / 완주하면 유효한 응수(상성 판정). 리셋은 포기 버튼.

4. **4·5길이 창이 빡빡해 리듬게임으로 읽힌다**.
   → 해결: 판단은 예고 1.0s, 창은 실행 전용으로 v0 같은-길이 승계 + 긴 초식 계수 0.5(넉넉히 시작해 D3 에서 줄임). 접근성 ×1.3 옵션.

5. **파견에서 "내가 아무것도 안 한다"** — 자동이면 관전만 남아 심심하다.
   → 해결: 매 수 예고 1초의 **초식 탭 선택**(색 대조 = 사부 대련과 같은 판단, 실행만 제자) + 무탭 자동은 "우세 중 성 높은 것"이라 개입하면 더 잘 이기는 여지(파해 지정·연환 노리기)를 남김. `select.byUser` 비율로 개입도 측정. 제자 성 상승·승패가 결과 화면에 숫자로.

6. **12성까지의 반복이 지루하다** — 성공 35회가 노동으로 읽힘.
   → 해결: 성은 3회마다 배지 연출로 잘게 보상, 11·12성은 **완파(파해)** 라는 질적 조건이라 "외운 자의 순간"이 두 번 박힘. 순차 해금이 초식을 하나씩 열어 후보·색 변화가 계속 새로움. `threshold`·성 계수는 D3 파라미터.

7. **전수가 "자동 이벤트"로 느껴진다** — 제자 1명·무공 1개라 고를 게 없어 클릭 한 번으로 지나감.
   → 해결: 전수 의식(시연 + 미러 + 스팅어 1.0s)으로 순간을 늘리고, 제자 카드에 「무공 슬롯 1/1 · 레벨 2 에서 +1」을 보여 "다음엔 무엇을 줄지 고른다"를 예고. 선택 플레이 자체는 M2(무공 2권 + 제자 레벨).

8. **6단 판정 결과가 한 수 안에 읽히지 않는다**.
   → 해결: 등급 = 색 + 한 글자 즉시 중앙 / 피해 = HP 바 애니메이션 / 빈틈 = 다음 예고 자리 「빈틈!」 배너 — 시간·위치 분리. 접근성 색 + 글자 + 형태.

- [안건 6] 문제점 2(오입력·미인식)의 발생 빈도가 과소추정 — 해결책이 인식률이 아닌 피드백만 다룬다 **(03 cycle 로 이월 — 결정 반영 재작성)**
  - 심각도: important
  - 출처: (b) 발생 가능성 — 문제점 2
  - 근거: 창 2.6~3.6s 안 3~5키를 스와이프(24px·1.5)로 넣는 전제 — 손가락을 떼지 않는 고속 연속 스와이프는 축 판정이 무너져 미인식이 군집으로 발생. 해결책(3종 피드백·리셋 하이라이트·로그 분리)은 전부 사후 설명이라 `timeout` 을 줄이지 못하고, 그 `timeout` 이 kill (b) 분모에 들어감.
  - 토의 유형: 문제 우선순위 재평가
