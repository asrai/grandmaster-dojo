# 일대종사 (一代宗師) — Grandmaster Dojo

슈퍼센트 AI Native 게임 PD 과제 — 아이들 아케이드 코어 루프 1사이클 프로토타입.

**재미 가설**: 손으로 익힌 초식이 자동화되는 순간이 보상이다 (성 = 자동화 권한).

## 플레이

**https://asrai.github.io/grandmaster-dojo/**

설치도 빌드도 내려받기도 없다 — 위 주소를 브라우저로 열면 그 자리에서 시작한다.

수치 정본을 JSON 모듈로 읽으므로 import attributes 를 지원하는 브라우저가 하한이다 — Chrome 123+ · Safari 17.2+ · Firefox 138+.

## 실행 (개발자용)

소스를 고쳐 가며 볼 때만 필요한 절이다 — 플레이만 할 것이라면 위 § 플레이 링크로 충분하고 Python 도 Node 도 깔 필요가 없다.

빌드 단계는 없지만 `index.html` 이 ESM 모듈(`src/`)을 로드하므로 **로컬 서버가 필수**다 — `file://` 로 직접 열면 모듈이 차단된다. 헤드리스 검증(§ 검증)은 Node 22+ 가 하한이다.

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

세로 화면(모바일 폭) 기준으로 만들어져 있다. 진행 상태는 **세션 한정**이라 새로고침하면 처음부터다.

## 조작

- 데스크톱: 방향키 ← ↑ → ↓ 또는 WASD · 리셋 `Space` / `Esc`
- 모바일: 화면 하단 십자 4버튼 + 리셋 (스와이프 없음)
- 키보드만으로도 전 화면을 조작할 수 있다 — 화면이 바뀌면 포커스가 그 화면 본문으로 옮겨 가고, 같은 화면이 조작으로 다시 그려질 때는 누르던 자리(같은 버튼, 그 버튼이 사라졌으면 같은 순번의 이웃)를 되찾고, 죽간·도전자 행·슬롯은 전부 진짜 버튼이라 탭 순회에 든다. 잠긴 버튼은 포커스를 받지 않는다.
- **응수 창 ×1.3 (쉬움)** 토글은 게임 화면 밖 **도구 띠**(로그 내보내기·봇 옆)에 있다 — 접근성 옵션의 정착지는 설정 화면이고, 그때까지 무대 안의 자리를 빌리지 않는다. `?tools=0` 으로 도구 띠를 숨기면 이 토글도 함께 숨는다.

## 소리

- **SFX 6종 + BGM 루프 1종**이 `assets/audio/` 의 Ogg/Opus 실파일로 재생된다 — 방향 키 타격음(칠 때마다 피치가 달라진다) · 후보 확정음 · 판정음 3계열(완파 / 우세·상쇄·열세 / 역파·피격) · 성 상승음.
- 브라우저 자동재생 정책상 **첫 입력 전에는 소리가 나지 않는다** — 아무 키나 탭 한 번이면 그 입력부터 난다.
- **음소거 토글**은 도장·도전자 선택 화면의 상단 띠 오른쪽에 있다 (「소리 켜짐 / 소리 꺼짐」). 끄면 BGM 루프도 함께 멈춘다.
- 어떤 사건에 어떤 소리가 붙는지는 `src/balance.data.json` 의 `audio` 표가 정하고, 재생은 `src/ui/audio.mjs` 한 모듈이 소유한다. 매핑이 없는 사건·등급은 로드나 재생 시점에 죽으므로 조용한 무음으로 지나가지 않는다.

## 규칙 (v2)

- **후보 필터 시퀀스**: 방향을 하나 누를 때마다 그 입력을 접두어로 갖는 장착 초식만 후보로 남는다. 후보가 하나가 되고 시퀀스를 끝까지 채우면 발동. 후보가 0이 되는 키는 **무시**되고 버퍼는 그대로다.
- **6단 공방 판정**: 파해 → 완파 / 속성 승 → 우세 / 동속성 → 상쇄 / 속성 패 → 열세 / 상대 절초의 파해 대상 → 역파 / 창 안 미완주 → 피격. 속성 삼각은 쾌 > 강 > 정 > 쾌이고 **파해가 삼각보다 우선**한다.
- **한 수**: 상대 예고 1.0s → 응수 창 `T = 2.6 + 0.5 × (길이 − 3)` → 교차 판정 → 연출 0.5s. HP 소진 또는 12수(잔여 HP 비교)로 끝난다.
- **성(成) 하나가 손의 권한이자 위력**: 성은 **초식마다** 1~12 인 단일 게이지다 (숙련도 0~100% 는 이 안으로 흡수·폐기). 계단이 곧 권한 — 2성 장착 · 5성 다음 식 학습 · 7성 원터치이고, 위력은 `N = 1 + 0.05 × 그 초식의 성`이라 같은 무공 안에서도 초식마다 다르다. 도전자도 도전자별 성 1개를 갖고 같은 식을 쓴다.
- **사부 대련 4차 · 재대련**: 도전자는 **A-1~A-4** 네 차수이고 앞 차수를 이기면 다음이 열린다. 4차는 절초 **월영자**를 쓰는 유일한 사부 대련 상대이고, 그것을 파하는 **파운현월**의 완파 무대이기도 하다. 이긴 도전자는 **도전자 선택** 화면에서 다시 칠 수 있는데, 대면마다 상대 성이 **+1 씩 오르고 +3 에서 멈추며** 재대련 승리에는 **재화가 나오지 않는다** — 파밍이 아니라 계단을 마저 밀기 위한 자리다.
- **도전자 선택 화면**: 대련·재대련은 `도장 → 도전자 선택 → 대련` 순으로 들어간다. 위쪽이 지금 칠 수 있는 도전자 목록(해금된 차수 전부)이고 아래가 그 도전자의 브리핑이며, 목록이 길어져도 목록만 스크롤하고 브리핑과 「대련 시작」은 바닥에 고정된다. 도전자의 **성은 숫자로 뜨지 않는다** — 난이도 신호는 목록 순서와 절초 유무뿐이고, 이미 이긴 상대는 회색 보통 굵기로 갈린다. 실전 슬롯은 **표시 전용**이다 — 대련 죽간과 같은 세로 카드가 좌우로 늘어설 뿐이고, 장착·해제는 도장 초식 행에서만 한다. 파해가 공개된 상대에서는 그 초식이 빠져 있으면 「무슨 일이 나는지」로 경고했다가, 도장에서 바꿔 돌아오면 금색 확인으로 바뀐다.
- **절초 공개는 대면 이력이 가른다**: **첫 대면**에는 상대 초식이 「미상」으로 접히고 절초는 존재만 소문으로 남는다 — 싸워 본 적 없는 상대의 초식을 아는 것이 성립하지 않기 때문이다. **한 번 이긴 뒤**로는 초식 3매와 **절초의 이름·파해 대상**이 공개된다(역파는 그 초식을 안 내면 애초에 일어나지 않는다 — 답을 가르치는 것이 1차 해법이다). 첫 대면 여부는 그 도전자의 재대련 회차가 0인지로 갈리고, 도전자 선택 화면의 목록 행과 브리핑이 같은 공개 층을 쓴다.
- **역파는 성으로 덜 아파진다**: 역파 피격은 `상대 피해 × max(0.4, 1 − 0.075 × max(0, 내 초식 성 − 상대 성))` 이다 — 키운 초식일수록 덜 맞지만 **관통 하한 40%** 아래로는 내려가지 않는다(절초는 여전히 무섭다). 감쇠는 맞았을 때의 보상이지 회피의 대체가 아니다.
- **적립 3단 → 순차 해금 → 12성 → 전수 → 파견**: 성은 세 구간으로 오른다 — **1~7성**은 수련 3회 또는 대련 유효 성공 1회로 1계단, **8~10성**은 대련 유효 성공 2회로 1계단이고 수련은 무효(8성 벽), **11성은 그 초식으로 낸 결정타 · 12성은 그 초식으로 낸 완파**다(순차·비소급, 한 수 최대 1계단). N식이 5성이면 N+1식을 배울 수 있다. 전 초식이 12성이면 그 무공이 제자에게 **무공 단위로 통째 복사**되고(사부는 그대로 보유), 제자는 전 초식을 1성부터 들고 파견에서 대신 구사한다 — 제자 규칙은 사부와 동형이되 상한이 10성이다.
- **파견 2단 · 임무**: 파견은 **B-1** 부터 시작한다 — 고정 상대라 갓 전수받은 1성 제자도 무지시 자동으로 이긴다. 이긴 뒤 열리는 **B-2 이후**는 상대 구성이 임무마다 랜덤(α·β·γ·δ 에서 3종, 절초 δ 도 나올 수 있다)이고 도전자 성이 차수마다 한 단계씩 오른다 — 같은 자리에 눌러앉을 수 없다. 진입은 **하드 잠금**이다: 제자의 **전 초식 최소 성**이 권장 성(5)에 닿아야 「파견 보내기」가 눌리고, 못 미치면 버튼이 비활성인 채 모자란 초식이 이름과 현재 성으로 뜬다(확인 팝업으로 넘길 수 없다). 한 초식만 뒤처져도 잠긴다.
- **제자 수련** (도장 제자 카드): 초식 하나를 골라 **걸어 두면** 실시간 경과로 그 초식의 제자 성이 오른다 — **1성당 30분**이고 **지정한 초식만** 오른다. 타이머는 **병렬**이라 그동안 사부의 수련·대련·전수가 그대로 돌아가고, 카드에는 진척 막대 1개와 초식별 성 4개가 나란히 서 어느 초식이 뒤처졌는지 한눈에 보인다. 7성에서 멈추며(그 위는 파견 유효 성공 전용) 지정을 다른 초식으로 옮겨도 두고 간 시간은 남아 있다가 돌아오면 이어 찬다.
- **7성 미만** 초식은 잔여 화살표가 키마다 0.5s 뒤 점등한다(수련 모드는 즉시). 7성부터는 지연 없이 전부 보이고 후보 탭 원터치가 열린다.

## 밸런스 수치 조정

- 수치 정본은 `src/balance.data.json` 하나다 — 값을 고치고 브라우저를 새로고침(또는 `node tests/kill-readout.mjs` 재실행)하면 브라우저와 헤드리스가 같은 값을 본다. 필드·타입·키 결합에 더해 **값의 의미 제약**(시간·HP·계단은 양의 정수, 확률·비율은 0~1, 창 벌점은 0 이상 1 미만)과 **성 축 상호관계**(장착 2 < 해금 5 < 원터치 7 ≤ 수련 적립 상한)가 어긋나면 폴백 없이 즉시 죽고, 어느 필드가 왜 틀렸는지가 화면(또는 stderr)에 뜬다.
- 실험 변형은 최상위 `rev` 로 구분하고, **`rev` 는 값 지문에 묶여 있다** — 형식은 `<판본>/<8자리 지문>`이라 값만 고치고 `rev` 를 그대로 두면 로드 시점에 죽으면서 그대로 붙여 넣을 새 `rev` 를 알려 준다. 내보낸 로그의 밸런스 지문에 `rev` 가 박혀 어느 변형에서 나온 회차인지 드러난다.
- 확정 반영만 커밋한다: JSON + `tests/harness.mjs` 의 파라미터 census 시드(하네스가 강제한다) + `docs/balance-log.md` 회차를 한 PR 로.

## 검증

```bash
node tests/harness.mjs        # 헤드리스 회귀 — 판정 등급·피해 정수·상태 전이·밸런스 게이트·봇 1사이클
node tests/kill-readout.mjs   # kill 판독 — 봇 1사이클을 만들어 (a)(b)(d)·ignore_rate 를 산출
node scripts/check-font-coverage.mjs   # 폰트 커버리지 — 서브셋이 못 덮는 글자를 열거한다
```

폰트는 사용 글자 기반 서브셋이라 **새 문구를 넣으면 커버리지 게이트가 red 로 잡는 것이 정상**이다. 그때는 `bash scripts/subset-fonts.sh` 로 `assets/fonts/` 의 woff2 를 다시 만들어 같은 커밋에 담는다 (생성에는 `fonttools`·`brotli` 와 Noto Serif KR 가변 폰트가 필요하며, 절차는 그 스크립트 헤더에 있다).

`src/balance.mjs`(콘텐츠 테이블 + `balance.data.json` 로더) · `src/core.mjs`(순수 로직) · `src/log.mjs`(로그 스키마) · `src/bot.mjs`(봇·헤드리스 사이클)는 DOM 을 모르므로 브라우저와 하네스가 같은 모듈을 쓴다. DOM 을 아는 코드는 `src/ui/` 아래에 있고, 그중 입력기 `src/ui/sequence-input.mjs` · 대련 루프 `src/ui/match.mjs` · 세션 상태 `src/ui/session.mjs` · 계측 배선 `src/ui/wiring.mjs` · 죽간 상태 `src/ui/tablet-state.mjs` · 표시 규약 `src/ui/theme.mjs` · 사운드 매핑 `src/ui/audio.mjs` · 프레임 예산 `src/ui/frame-budget.mjs` 는 DOM-free 라 하네스가 함께 회귀한다 — 파견 밸런스 게이트도 사본이 아니라 이 대련 루프를 가상 시계로 돌려 검증하고, 화면과 헤드리스 사이클은 같은 계측 배선 한 벌 위에 각자의 렌더·구동만 얹는다.

### 로그 내보내기 · kill 판독

1. 로컬 서버로 열고 1사이클을 플레이한다 (도장 → 수련 → 사부 대련 → 12성 → 전수 → 파견 B-1 → 결과). 개발·QA 반복 검증은 화면 왼쪽 위 **개발자 치트** 로 성을 직접 주입해 임의 시점에서 시작할 수 있다 — 기본 숨김이고 봇 구동 중에는 잠기며, 한 번이라도 주입한 세션은 로그에 플래그가 박혀 회차·kill 표본에서 빠진다.
2. 헤더의 **로그 내보내기** 를 누르면 세션 버퍼가 `dojo-log-<시각>.json` 으로 내려온다. 스키마 위반이 있으면 위반 목록이 같은 파일에 실리고 경고가 뜬다.
3. `node tests/kill-readout.mjs <내려받은 파일>` 로 판독한다 — 필드 결손과 로그 스키마 전 종류의 방출을 먼저 검사한 뒤 kill (a) `first_fire_t` · (b) 완주율 · (d) `cycle_done_t` 와 선행 게이트 `ignore_rate` 를 pass/fail 로 찍는다. (c) 는 설문 축이라 로그 밖이다. 인자 없이 부르면 봇 1사이클을 그 자리에서 만들어 판독하고, `--emit <경로>` 는 그 로그를 파일로도 남긴다.
4. 종료 코드는 **판독 가능성**이다 — kill 미달은 red 가 아니고, 필드 결손 · 스키마 위반 · 산식 입력(`key`·`fire`·`cycle`) 결손 · `cycle_done` 부재(1사이클 미완주) · 파일 읽기·파싱 실패 · 알 수 없는 내보내기 스키마가 red 다. `ignore`·`reset`·`timeout` 처럼 **조건부**인 이벤트가 없는 것은 red 가 아니다(깔끔하게 친 사람의 로그가 그렇다) — 그 축의 보조 지표만 비고 판독은 이어진다. 전 종류 방출은 계측 빌드 자체의 검증이라 인자 없는 자체 생성 모드에서만 강제한다.
5. 두 사이클 이상 플레이한 로그는 **첫 `cycle_done` 까지만** 센다 (제외 건수를 함께 찍는다).
6. **모집단이 섞이면 판독기가 그렇게 말한다** — 봇을 중간에 멈추고 사람이 이어 친 로그는 봇 구간을 (a)(b)·`ignore_rate` 에서 빼고 (d) 를 `?`(판독 불가)로 두며, 「응수 창 ×1.3」을 사이클 중 전환한 로그는 (b) 를 `?` 로 둔다(기본 창과 ×1.3 창의 분모가 섞인다). **수동 창 표본이 20 미만인 로그도 (b) 가 `?` 다** — 원터치 창이 분모에서 빠지므로 7성 이후 모집단이 줄고, 그 소표본으로 낸 비율은 손의 증거가 아니다. 치트를 한 번이라도 쓴 세션은 (b)(d) 판독 자체가 막힌다. 내보낸 뒤 `BALANCE` 를 튜닝하면 밸런스 지문 불일치 경고가 뜬다.
7. 판독기는 kill 4항 옆에 **신규 지표**도 로그만으로 찍는다 — 재대련 회차 분포·결정타 배분과 의도 일치율·8성 벽 횟수(사부 축)와 파견 차수별 조합·승패·제자 수련 성 상승분·그때 사부가 하던 일(제자 축).

**봇 v2** (헤더의 «봇 v2 실행») — 사람 속도(반응 0.45~0.65s · 키당 0.26~0.38s · 15% 미입력)로 손과 **같은 입력 경로**를 두드려 1사이클을 자동 완주한다(파견 무지시). 봇 수치는 페이스 회귀 참고치이고 kill 판정 표본이 아니다.

**1시간 수련 시뮬** (도장 버튼) — 방치 축을 압축해 보여 준다. 재화를 주고, **걸어 둔 제자 수련의 시계도 1시간 앞당긴다** — 평가자가 실제로 30분을 기다리지 않고 방치 루프의 결과를 볼 수 있게 하는 자리다(게임 수치인 1성당 30분 자체는 그대로다). 재화는 획득·표시만 하고 소비처가 없다 (M2+).

**유도 툴팁** (도장 화면 한정) — 지금 눌러야 할 버튼 하나에 말풍선이 붙는다. 최초 진입에는 시작점을, 그 뒤로는 잠겨 있던 버튼이 풀리는 순간 그 버튼을 가리키며, 눌렀거나 다시 잠기면 사라지고 같은 버튼에 두 번 뜨지 않는다. 안내일 뿐이라 입력을 받지 않으므로 대련의 응수 창·방향키에는 영향이 없다.

**도장 화면** — 맨 위는 사부·제자 실루엣이 선 도장 정경 배너이고 그 아래 본문만 세로로 스크롤한다. 초식 행마다 **12칸 성 계단 + 다음 계단 안내 한 줄**(「다음 5성 — 파운현월이 열린다」·「다음 8성 — 수련은 여기까지, 대련으로만」)이 서고, 만성(12성)·잠긴 행은 계단을 접고 성 배지만 남긴다 — 전부 금색이거나 전부 빈 계단은 정보량이 0인데 세로만 먹기 때문이고, 회수한 그 세로가 제자 블록의 자리다. 본문 아래에는 **제자 블록**(수련 지정 · 진척 막대 · 남은 시간 · 초식별 성 4열)이 선다 — 도전자 정보는 홈에 두지 않고 「대련」이 여는 도전자 선택 화면이 전부 진다.

**도장 액션 바** (도장 화면 한정) — `대련` · `전수` · `파견` 세 버튼은 스크롤 흐름 밖 화면 하단 밴드에 고정돼 진입 첫 화면부터 항상 보인다. 잠긴 버튼도 자리를 지키고 그 아래 한 줄에 잠금 사유(파견은 가장 뒤처진 초식을 이름과 현재 성으로 대 「행운유수 3성 · 권장 5성」)를 띄우므로 밴드 높이는 진행 상태와 무관하게 같다. 초식 행은 접고 펴는 것이 없는 한 형태이고 이름은 읽는 자리다 — 누를 수 있는 것은 우측 액션 버튼(수련·장착·해제·배우기)뿐이다. 시퀀스 화살표는 도장에 두지 않는다 — 시퀀스는 수련의 구결 족자에서 익히고 대련에서는 딜레이드 힌트가 알려준다.

**결과 화면** — 7화면 중 유일하게 상단 띠가 없어 무대가 화면 맨 위에서 곧장 시작하고, 승패를 문구보다 **자세로 먼저** 말한다 — 이긴 쪽이 서고 진 쪽이 엎드리며, 지면 서 있는 쪽이 도전자·쓰러진 쪽이 사부로 자리가 맞바뀐다. 아래 정산은 **고정 3블록 → 구분선 → 조건부 블록**의 2층이라 어떤 판에서도 순서가 같다: 위는 **판정 분포**(6단 각각의 횟수 6열) · **결정타**(끝낸 초식, 못 끝냈으면 그 사실) · **재화**이고, 아래는 있을 때만 붙는 **성 변화**(초식마다 12칸 계단 + `8성 → 9성`, 이번 판에 오른 칸만 발광) · **전리품** · **해금**이다. **져도 성 변화와 판정 분포는 그대로 보인다** — 적립 단위가 유효 성공이라 져도 성은 오르기 때문이고, 그 판에서 재화는 「없음」이며 전리품·해금은 붙지 않는다. 재대련 승리는 재화 줄이 「재대련은 재화를 주지 않는다」 문장으로 바뀌고 전리품도 붙지 않는다. 성이 오른 초식이 많아도 **정산부만 스크롤**하고 하단 확정 버튼은 늘 보인다. 파견에서 제자가 지면 무대에 도전자만 서는데, 이는 결손이 아니라 제자의 엎드린 실루엣이 아트 계약의 제자 4자세에 없기 때문이다 — 선 자세를 눕혀 때우지 않는다.

**전수 장면** — 사부가 시범을 보이고 제자가 그 등 뒤에서 따라 한다. 처음에는 제자의 팔 각도가 어긋나 있다가 **사부와 나란해지는 전이 하나**로 「익혔다」를 말하며, 화면에서 빛나는 것은 두 사람 위에 세로로 선 **무공 인장** 하나뿐이다. 아래는 초식마다 한 줄인 **이관 행**이고(초식명·사부 성 / 시퀀스·제자 성 계단), 사부 성은 금·제자 성은 청이며 제자 계단은 12칸 중 1칸만 켜진다 — 건너간 것이 초식 4개가 아니라 무공 하나이고 제자는 1성부터 시작하기 때문이다. 바닥의 버튼은 연출 중에는 「건너뛰기」, 완료 후에는 「도장으로」로 자리를 지킨 채 뜻만 바뀐다.
