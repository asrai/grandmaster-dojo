## 1. 재미 가설 / 목표

**"손으로 익힌 초식이 자동화되는 순간이 보상이다."**

- 방치형의 성장 자원은 보통 시간과 재화다. 이 게임은 **플레이어의 손맛(수동 입력 성공 횟수)** 을 성장 자원으로 삼는다. 초식은 수동으로 N회 성공해야만 자동화(제자에게 전수)된다 — 숙련도 = 자동화 권한.
- 유저에게 주려는 핵심 경험 (1사이클 안에서 3번 반복):
  1. **긴장**: 적의 예고 동작을 읽고 제한 시간 안에 방향 시퀀스를 정확히 입력
  2. **숙달**: 힌트가 사라져도 손이 기억하는 순간 (힌트 페이드아웃)
  3. **해방**: "전수 완료" — 방금까지 내가 치던 초식을 제자가 대신 치기 시작하고, 나는 다음 초식으로 손을 옮긴다
- 검증하려는 질문: *수동 조작의 피로를 "자동화 해금"이라는 보상으로 바꾸면, 순수 방치형보다 초반 5분 몰입이 높아지는가?*

## 2. 핵심 메커니즘

### 2-1. 세계·역할
- 플레이어 = 도장의 **사부**. 문하생(제자)이 도전자와 대련한다.
- 사부가 직접 익힌 초식만 제자에게 **전수**할 수 있다. 전수된 초식은 제자가 자동으로 사용한다.

### 2-2. 대련 (전투 페이스: 실시간, 1:1 인카운터)
- 도전자는 3종 공격 중 하나를 **예고(telegraph)** 한다 (예고 → 발동까지 `windowMs`).
- 각 공격에는 상성 초식이 1:1로 대응한다 (상성표 고정, 가위바위보 아님 — 읽기 부담 최소화):

| 도전자 공격 | 상성 초식 | 입력 시퀀스 (방향키/스와이프) |
|---|---|---|
| 횡베기 | 유운보 (流雲步) | ↓ → |
| 찌르기 | 반격장 (反擊掌) | ← ↑ → |
| 내려치기 | 천붕각 (天崩脚) | ↑ ↑ ↓ ← |

- **판정**: 창 안에 시퀀스를 정확히 완주 → 성공(적 피해 + 숙련 +1). 오입력 1회 → 시퀀스 리셋(창 유지). 창 만료 → 실패(사부/제자 피해).
- 도전자 HP 3타. 격파 시 **원(元)** 보상 + 다음 도전자 등장(공격 조합·속도 소폭 상승).

### 2-3. 숙련도 → 전수(자동화)
- 초식별 숙련도 `mastery`. 수동 성공 1회당 +1. `threshold` 도달 시 **전수 버튼 활성** → 누르면 `auto=true`.
- 자동화된 초식은 해당 공격이 예고될 때 제자가 `autoDelay` 후 성공 확률 `autoEff` 로 자동 응수. 실패하면 사부가 남은 창 안에 수동으로 커버 가능(수동 성공 시 `autoEff += effGain`, 상한 1.0).
- 힌트(시퀀스 화살표)는 `mastery < hintUntil` 동안만 표시. 이후 초식 이름만 표시 → "손이 기억하는" 구간.

### 2-4. 도장 성장
- 원으로 **두루마리** 구매 = 새 초식 학습 개시 (초식 2·3은 잠김 상태로 시작).
- 초식 3종 모두 전수 후 **진법 「일자진」** 구매 가능: 제자 2명 배치 → 자동 응수 확률 +0.15, 대련 속도 ×1.5. 진법 구매 = 코어 루프 1사이클 완료 마커.
- **수련 시뮬(오프라인 보상)**: "1시간 수련" 버튼 — 현재 자동화 상태로 1시간 방치했을 때 벌 원을 즉시 지급 (평가자가 방치형 축을 3분 안에 체감하도록 압축한 장치).

### 2-5. 진행 흐름 (1사이클)
```
수동 대련(유운보) → 원·숙련 → 유운보 전수 → 제자 자동 응수 시작
→ 원으로 반격장 두루마리 → 수동 학습 → 전수
→ 천붕각 두루마리 → 수동 학습 → 전수
→ 일자진 구매 → [1사이클 완료] → 도전자 난이도 상승, 재플레이
```

### 2-6. 조작
- 데스크톱: 방향키 ← ↑ → ↓ / 모바일: 4방향 스와이프. 버튼: 전수 · 두루마리 구매 · 진법 · 수련 시뮬.

## 3. 밸런싱 / 수치 설계

목표 페이스: **첫 전수 ≤ 90초 · 3초식 전수 ≤ 4분 · 진법 ≤ 5분** (평가자 1회 플레이 = 1사이클 완주).

| 파라미터 | 유운보 | 반격장 | 천붕각 | 근거 |
|---|---|---|---|---|
| 시퀀스 길이 | 2 | 3 | 4 | 난이도 곡선 = 입력 길이 |
| 입력 창 `windowMs` | 2200 | 2600 | 3000 | 입력 1타당 ~600ms + 읽기 400ms |
| 전수 임계 `threshold` | 6 | 8 | 10 | 성공률 70% 가정 시 각 ~9·11·14회 시도 |
| 힌트 유지 `hintUntil` | 3 | 4 | 5 | 임계의 절반 = "외워서 치는" 구간 확보 |
| 두루마리 가격 | – | 60원 | 150원 | 직전 초식 자동화 후 ~40초 내 도달 |
| 초기 `autoEff` | 0.6 | 0.6 | 0.6 | 전수 직후에도 사부 커버 필요 → 손 안 놓게 |
| `effGain` (수동 커버 성공당) | +0.08 | | | 5회 커버로 1.0 |
| `autoDelay` | 창의 45% | | | 실패 시 사부 커버 시간 확보 |

| 공통 파라미터 | 값 | 근거 |
|---|---|---|
| 도전자 HP | 3 | 3타 = 초식 3종 순환 1바퀴 |
| 격파 보상 | 10원 × (1 + 0.15 × 격파 수) | 완만한 인플레 |
| 성공 1타 보상 | 2원 | 수동 입력 자체에 즉시 보상 |
| 예고 간격 | 1200ms → 격파마다 −40ms (하한 600) | 자동화 후 손이 비는 만큼 밀도 상승 |
| 사부 HP | 5, 실패당 −1, 격파 시 +1 회복 | 패배는 "초기화"가 아니라 도전자 리셋만 |
| 진법 가격 | 300원 | 3초식 전수 직후 ~60초 자동 수입 |
| 수련 시뮬 1시간 | Σ(전수 초식 autoEff) × 예고빈도 × 2원 × 3600 × 0.3 | 방치 효율 30% (실플레이 유인) |

수치는 `index.html` 상단 `BALANCE` 객체 하나로 모으고, 튜닝 결과는 `docs/balance-log.md` 에 회차별 기록.

## 4. 범위 (Scope)

**만드는 것**
- 초식 3종 수동 입력·판정, 숙련도 → 전수(자동화), 도전자 인카운터 루프, 원 경제, 두루마리 2종, 진법 1종, 수련 시뮬, 세션 타이머 + 1사이클 완료 배너, localStorage 저장, 키보드+터치

**만들지 않는 것**
- 진법 2종 이상·진법 간 상성, 다대다 전투, 스토리·캐릭터 아트(기호·실루엣·이펙트로 대체), 사운드 다수(성공/실패/전수 3음), 광고·IAP·BM, 서버·계정, 밸런스 자동 조정

## 5. 성공 기준

| # | 기준 | 측정 |
|---|---|---|
| S1 | 첫 전수 도달 시간 ≤ 90초 (미조작 튜토리얼 없이) | 인게임 타이머 로그 |
| S2 | 5분 내 진법 구매(1사이클 완주) 도달률 ≥ 70% | 테스터 5인 플레이 로그 |
| S3 | 힌트 소멸 후 수동 성공률 ≥ 60% (초식별) | 로그 |
| S4 | 테스터 정성: "전수 순간이 기분 좋았다" 5점 중 4 이상 (5인 중 3인) | 사후 설문 1문항 |
| S5 | 자동화 이후에도 사부 수동 커버 입력이 세션당 ≥ 10회 발생 (손을 안 놓는가) | 로그 |
| S6 | 모바일 Safari·Chrome, 데스크톱 Chrome에서 60fps·입력 지연 체감 없음 | 수동 확인 |
