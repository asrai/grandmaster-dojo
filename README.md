# 일대종사 (一代宗師) — Grandmaster Dojo

슈퍼센트 AI Native 게임 PD 과제 — 아이들 아케이드 코어 루프 1사이클 프로토타입.

**재미 가설**: 손으로 익힌 초식이 자동화되는 순간이 보상이다 (숙련도 = 자동화 권한).

## 실행

빌드 단계는 없지만 `index.html` 이 ESM 모듈(`src/`)을 로드하므로 **로컬 서버가 필수**다 — `file://` 로 직접 열면 모듈이 차단된다.

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

세로 화면(모바일 폭) 기준으로 만들어져 있다. 진행 상태는 **세션 한정**이라 새로고침하면 처음부터다.

## 조작

- 데스크톱: 방향키 ← ↑ → ↓ 또는 WASD · 리셋 `Space` / `Esc`
- 모바일: 화면 하단 십자 4버튼 + 리셋 (스와이프 없음)

## 규칙 (v2)

- **후보 필터 시퀀스**: 방향을 하나 누를 때마다 그 입력을 접두어로 갖는 장착 초식만 후보로 남는다. 후보가 하나가 되고 시퀀스를 끝까지 채우면 발동. 후보가 0이 되는 키는 **무시**되고 버퍼는 그대로다.
- **6단 공방 판정**: 파해 → 완파 / 속성 승 → 우세 / 동속성 → 상쇄 / 속성 패 → 열세 / 상대 절초의 파해 대상 → 역파 / 창 안 미완주 → 피격. 속성 삼각은 쾌 > 강 > 정 > 쾌이고 **파해가 삼각보다 우선**한다.
- **한 수**: 상대 예고 1.0s → 응수 창 `T = 2.6 + 0.5 × (길이 − 3)` → 교차 판정 → 연출 0.5s. HP 소진 또는 12수(잔여 HP 비교)로 끝난다.
- **숙련이 성의 선행 조건**: 숙련(초식) 0~100% 는 손의 권한 — 30% 장착 · 100% 원터치. 성(무공) 1~12 는 깨달음의 증표이자 위력 `N = 1 + 0.05 × 성`이고, **무공의 전 초식을 100% 로 익혀야(입문) 성 게이지가 열린다** — 그 전의 발동은 숙련만 올리고 성은 1 에 머문다.
- **순차 해금 → 입문 → 12성 → 전수 → 파견**: N식을 100% 로 채워야 N+1식을 배운다. 전 초식이 100% 가 되면 입문이 뜨고 그때부터 유효 성공마다 성 포인트가 쌓여 12성에 닿는다. 12성이면 그 무공이 제자에게 **무공 단위로 통째 복사**되고(사부는 그대로 보유), 제자는 전 초식을 1성부터 들고 파견에서 대신 구사한다.
- 미완성 초식은 잔여 화살표가 키마다 0.5s 뒤 점등한다(수련 모드는 즉시).

## 검증

```bash
node tests/harness.mjs        # 헤드리스 회귀 — 판정 등급·피해 정수·상태 전이·밸런스 게이트·봇 1사이클
node tests/kill-readout.mjs   # kill 판독 — 봇 1사이클을 만들어 (a)(b)(d)·ignore_rate 를 산출
```

`src/balance.mjs`(데이터) · `src/core.mjs`(순수 로직) · `src/log.mjs`(로그 스키마) · `src/bot.mjs`(봇·헤드리스 사이클)는 DOM 을 모르므로 브라우저와 하네스가 같은 모듈을 쓴다. DOM 을 아는 코드는 `src/ui/` 아래에 있고, 그중 입력기 `src/ui/sequence-input.mjs` · 대련 루프 `src/ui/match.mjs` · 세션 상태 `src/ui/session.mjs` · 계측 배선 `src/ui/wiring.mjs` 는 DOM-free 라 하네스가 함께 회귀한다 — 파견 밸런스 게이트도 사본이 아니라 이 대련 루프를 가상 시계로 돌려 검증하고, 화면과 헤드리스 사이클은 같은 계측 배선 한 벌 위에 각자의 렌더·구동만 얹는다.

### 로그 내보내기 · kill 판독

1. 로컬 서버로 열고 1사이클을 플레이한다 (도장 → 수련 → 사부 대련 → 입문 → 전수 → 파견 → 결과).
2. 헤더의 **로그 내보내기** 를 누르면 세션 버퍼가 `dojo-log-<시각>.json` 으로 내려온다. 스키마 위반이 있으면 위반 목록이 같은 파일에 실리고 경고가 뜬다.
3. `node tests/kill-readout.mjs <내려받은 파일>` 로 판독한다 — 필드 결손과 17종 이벤트 방출을 먼저 검사한 뒤 kill (a) `first_fire_t` · (b) 완주율 · (d) `cycle_done_t` 와 선행 게이트 `ignore_rate` 를 pass/fail 로 찍는다. (c) 는 설문 축이라 로그 밖이다. 인자 없이 부르면 봇 1사이클을 그 자리에서 만들어 판독하고, `--emit <경로>` 는 그 로그를 파일로도 남긴다.
4. 종료 코드는 **판독 가능성**이다 — kill 미달은 red 가 아니고, 필드 결손 · 스키마 위반 · 산식 입력(`key`·`fire`·`cycle`) 결손 · `cycle_done` 부재(1사이클 미완주) · 파일 읽기·파싱 실패 · 알 수 없는 내보내기 스키마가 red 다. `ignore`·`reset`·`timeout` 처럼 **조건부**인 이벤트가 없는 것은 red 가 아니다(깔끔하게 친 사람의 로그가 그렇다) — 그 축의 보조 지표만 비고 판독은 이어진다. 17종 전량 방출은 계측 빌드 자체의 검증이라 인자 없는 자체 생성 모드에서만 강제한다.
5. 두 사이클 이상 플레이한 로그는 **첫 `cycle_done` 까지만** 센다 (제외 건수를 함께 찍는다).
6. **모집단이 섞이면 판독기가 그렇게 말한다** — 봇을 중간에 멈추고 사람이 이어 친 로그는 봇 구간을 (a)(b)·`ignore_rate` 에서 빼고 (d) 를 `?`(판독 불가)로 두며, 「응수 창 ×1.3」을 사이클 중 전환한 로그는 (b) 를 `?` 로 둔다(기본 창과 ×1.3 창의 분모가 섞인다). 내보낸 뒤 `BALANCE` 를 튜닝하면 밸런스 지문 불일치 경고가 뜬다.

**봇 v2** (헤더의 «봇 v2 실행») — 사람 속도(반응 0.45~0.65s · 키당 0.26~0.38s · 15% 미입력)로 손과 **같은 입력 경로**를 두드려 1사이클을 자동 완주한다(파견 무지시). 봇 수치는 페이스 회귀 참고치이고 kill 판정 표본이 아니다.

**1시간 수련 시뮬** (도장 버튼) — 방치 축을 재화로 압축해 보여 준다. 재화는 획득·표시만 하고 소비처가 없다 (M2+).

**유도 툴팁** (도장 화면 한정) — 지금 눌러야 할 버튼 하나에 말풍선이 붙는다. 최초 진입에는 시작점을, 그 뒤로는 잠겨 있던 버튼이 풀리는 순간 그 버튼을 가리키며, 눌렀거나 다시 잠기면 사라지고 같은 버튼에 두 번 뜨지 않는다. 안내일 뿐이라 입력을 받지 않으므로 대련의 응수 창·방향키에는 영향이 없다.

**도장 액션 바 · 초식 아코디언** (도장 화면 한정) — `대련` · `전수` · `파견` 세 버튼은 스크롤 흐름 밖 화면 하단 밴드에 고정돼 진입 첫 화면부터 항상 보인다. 잠긴 버튼도 자리를 지키고 그 아래 한 줄에 잠금 사유를 띄우므로 밴드 높이는 진행 상태와 무관하게 같다. 초식 목록은 한 번에 한 줄만 시퀀스를 펼치는 아코디언이며, 기본 펼침은 유도 툴팁이 가리키는 초식 줄이고, 안내가 초식 줄에 없으면 첫 장착 초식이다. 줄 이름을 눌러 다른 줄로 옮기거나 접을 수 있고 그 선택은 안내가 다른 초식 줄로 옮겨갈 때까지 유지된다.
