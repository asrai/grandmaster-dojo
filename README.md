# 일대종사 (一代宗師) — Grandmaster Dojo

슈퍼센트 AI Native 게임 PD 과제 — 아이들 아케이드 코어 루프 1사이클 프로토타입.

**재미 가설**: 손으로 익힌 초식이 자동화되는 순간이 보상이다 (숙련도 = 자동화 권한).

## 실행
- `index.html` 을 브라우저로 열기 (의존성 없음). 모바일은 세로 화면 권장.
- 로컬 서버: `python3 -m http.server 8000` → http://localhost:8000

## 조작
- 데스크톱: 방향키 ← ↑ → ↓ / 모바일: 4방향 스와이프
- 도전자의 예고를 보고 상성 초식의 시퀀스를 제한 시간 안에 입력

## 문서
- `docs/PRD.md` — 기획 의도·메커니즘·밸런싱·범위·성공 기준
- `docs/ai-log.md` — AI 제안 채택/수정/폐기 기록
- `docs/balance-log.md` — 튜닝 회차 기록

## 알려진 제약 (v0)
- 게임 루프가 `requestAnimationFrame` 기반이라 탭이 백그라운드로 가면 자동 대련이 멈춘다 (방치 축은 "수련 시뮬" 버튼으로 압축 시연).
- 헤드리스 검증: `docs/balance-log.md` 0-a 회차 참조.
