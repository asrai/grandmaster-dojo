# 화면 스크린샷 (현행 빌드)

`/gamedev-ui` 재설계의 입력 자료. 실제 플레이(키보드 입력)로 진행하며 `#stage` 영역만 촬영했다 —
논리 해상도 393×852, device pixel ratio 2, 검증 도구 버튼(레터박스 영역)은 프레임 밖이다.

| 파일 | 화면 | 상태 |
|---|---|---|
| `01-dojo-initial` | 도장 | 진입 직후 — 입문 전, 유운보만 학습, 유도 툴팁 노출 |
| `02-train-idle` | 수련 | 창이 열린 대기 상태, 구결 + 화살표 힌트 |
| `03-train-input-partial` | 수련 | ↓→ 까지 입력한 중간 상태 |
| `04-train-success` | 수련 | 성공 오버레이 (등급 마크 없음) |
| `05-dojo-after-training` | 도장 | 유운보 졸업 후 — 숙련 30%, 슬롯 1 장착, 대련 해금 |
| `06-duel-telegraph` | 사부 대련 | 예고 구간 — 벽산도 + 「이기는 색」 병기 |
| `07-duel-verdict-crush` | 사부 대련 | 완파 판정 오버레이 |
| `08-result-duel-win` | 결과 | 대련 승리 — 재화 + 차수 해금 |
| `09-dojo-initiated-rank12` | 도장 | 입문 완료 · 12성 — 성 게이지 개방, 전수 해금 |
| `10-dojo-row-expanded` | 도장 | 아코디언 — 마지막 행(파운현월) 펼침 |
| `11-transmit` | 전수 | 사부 → 제자 아이콘 도착 후 |
| `12-dispatch-preview` | 도전자 예고 | 절초 월영자 공개 + 제자 세팅 |
| `13-dispatch-telegraph` | 파견 관전 | 예고 구간 — 지시 아이콘 4종 |
| `14-dispatch-verdict` | 파견 관전 | 완파 판정 오버레이 |
| `15-result-dispatch` | 결과 | 파견 승리 — 제자 성 상승 |

미촬영 변형: 패배 결과(재도전 버튼), 피격·역파 판정, 빈틈 예고, 파견 지시 선택 상태.
